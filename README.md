# portfolio-yuri

Meu portfólio pessoal construído com React 19, TypeScript, Vite e Tailwind CSS v4.

## 🚀 Tecnologias
- **React 19**
- **TypeScript**
- **Vite 8**
- **Tailwind CSS v4**

## 💻 Como executar o projeto

```bash
# Instalar dependências
npm install

# Executar em modo de desenvolvimento
npm run dev

# Build de produção
npm run build
```
